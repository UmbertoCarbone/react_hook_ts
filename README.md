# React Hook Playground

Questo progetto nasce come eserciziario personale per ripassare e sperimentare gli hook di React considerati più "difficili" o avanzati.

## Hook trattati
- `useReducer`
- `useMemo`
- `useCallback`
- `useRef`
- Custom Hooks
- Browser Storage (localStorage/sessionStorage con hook personalizzati)

Ogni esercizio è pensato per essere semplice, chiaro e focalizzato su un solo concetto alla volta.

---

**Obiettivo:**

Allenare la comprensione e l'uso pratico degli hook React più avanzati, con esempi concreti e codice ben organizzato.
